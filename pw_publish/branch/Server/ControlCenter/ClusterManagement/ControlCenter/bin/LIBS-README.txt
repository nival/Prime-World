Сборки .NET Framework, удалённые из этой папки

Что здесь лежало
    System.Web.Mvc.dll             — ASP.NET MVC, каркас веб-приложения
    System.Web.Routing.dll         — маршрутизация запросов
    System.Web.Abstractions.dll    — абстракции веб-контекста
    System.ComponentModel.DataAnnotations.dll — атрибуты валидации моделей

Для чего использовалось
    Веб-интерфейс центра управления кластером: страницы администрирования
    серверов, маршруты, валидация форм. Код самого приложения остаётся
    в репозитории.

Почему удалено
    Это сборки Microsoft из состава .NET Framework и ASP.NET MVC.
    Они устанавливаются вместе с платформой, и включать их копии
    в публикуемый репозиторий нет ни необходимости, ни разрешения.

Как восстановить для сборки
    Установить .NET Framework и ASP.NET MVC соответствующей версии,
    либо восстановить пакеты через NuGet — сборки подтянутся сами.
