SwfChecker — УДАЛЕНО ИЗ ПУБЛИКАЦИИ

Что здесь лежало
    Утилита проверки flash-роликов интерфейса вместе с рантаймом,
    от которого она зависела:
        fmodex.dll, fmod_event.dll, fmod_event_net.dll — звуковой движок
            FMOD Ex (Firelight Technologies), коммерческое middleware
        zlib1.dll — распаковка сжатых swf (лицензия zlib, свободная)
        исполняемый файл проверяльщика и вспомогательные библиотеки

Для чего использовалось
    Проверка корректности swf-файлов интерфейса перед сборкой:
    наличие нужных символов, отсутствие ошибок разметки,
    воспроизводимость звуковых событий внутри роликов.

Почему удалено
    Папка удалена целиком из-за библиотек FMOD в её составе:
    лицензия Firelight Technologies не разрешает распространение SDK.
    Подробности — Vendor/fmod/README.txt.

Чем заменяется
    Инструменты проверки swf остаются в FlashUI: SwfValidator.exe
    и скрипты ValidateSwf.bat, Swf2Xml.bat.
