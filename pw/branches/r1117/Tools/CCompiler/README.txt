Компилятор Microsoft Visual C++ 2008 — УДАЛЕНО ИЗ ПУБЛИКАЦИИ

Что здесь лежало
    Компилятор и его окружение (20 файлов), версия 15.00.21022.08:
        cl.exe, c1xx.dll, c2.dll — фронтенд и бэкенд компилятора C++
        mspdb80.dll — работа с отладочными базами
        1033/ — ресурсы сообщений (clui.dll, linkui.dll, nmakeui.dll и другие)
        заголовки CRT: math.h, sal.h, crtdefs.h, vadefs.h
        CodeAnalysis/ — файлы статического анализа

Для чего использовалось
    Сборка проекта фиксированной версией компилятора без установки
    Visual Studio на машину сборки — распространённая практика
    для повторяемости сборок.

Почему удалено
    Компилятор — часть Microsoft Visual Studio 2008 и распространяется
    по её лицензии. Свободно распространять разрешено только компоненты,
    прямо перечисленные как redistributable; cl.exe в их число не входит.

Как восстановить для сборки
    Установить Visual Studio 2008 (либо более новую с набором
    инструментов v90) и собирать её компилятором.
