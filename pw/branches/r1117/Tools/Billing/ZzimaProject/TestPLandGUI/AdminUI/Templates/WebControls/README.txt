Коммерческие компоненты ASP.NET — УДАЛЕНО ИЗ ПУБЛИКАЦИИ

Что здесь лежало
    Charts/System.Web.DataVisualization.dll и .Design.dll
        компоненты построения графиков, Microsoft Corporation
    eWorld/eWorld.UI.dll
        набор веб-элементов управления, Excentrics World,
        Copyright 2000-2007, eworldui.net
    DNJ/Org.Eurekaa.DNJ.dll, .UI.dll, .Ext.dll
        компоненты Eurekaa.org

Для чего использовалось
    Административный веб-интерфейс биллинга: графики платежей
    и статистики, элементы форм, календари и таблицы.
    Разметка страниц и код интерфейса остаются в репозитории —
    удалены только сторонние сборки, от которых они зависят.

Почему удалено
    Сторонние коммерческие компоненты, публичной лицензии на
    перераспространение не имеют.

Как восстановить для сборки
    Microsoft Chart Controls входят в .NET Framework 4.0 и новее
    (сборка System.Web.DataVisualization). Остальные компоненты
    требуют лицензии соответствующих правообладателей либо замены
    на современные аналоги.
