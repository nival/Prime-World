C#-обёртки FMOD Ex — УДАЛЕНО ИЗ ПУБЛИКАЦИИ

Что здесь лежало
    Официальные биндинги FMOD Ex для C#, поставляемые вместе с SDK:
        fmod.cs         — основной API (система, каналы, звуки)
        fmod_dsp.cs     — цифровая обработка сигнала
        fmod_errors.cs  — расшифровка кодов ошибок
        fmod_event.cs   — событийная система FMOD
    Заголовок файлов: "FMOD Ex - C# Wrapper. Copyright (c),
    Firelight Technologies Pty, Ltd. 2004-2008."

Для чего использовалось
    Звуковой редакторский плагин: прослушивание и настройка звуков
    прямо в инструментах разработки.

Почему удалено
    Это код Firelight Technologies из состава FMOD SDK, а не код проекта.
    Лицензия FMOD не разрешает распространение SDK.
    Подробности: pw/branches/r1117/Vendor/fmod/README.txt

Что осталось
    Код плагина, написанный в проекте и вызывающий этот API, остаётся
    в этой папке. Для сборки положите сюда файлы обёрток из своей
    копии FMOD Ex SDK.
