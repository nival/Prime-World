Библиотеки, удалённые из этой папки

UniFlash использовал две сторонние сборки. Файлы .meta рядом оставлены —
это метаданные Unity с идентификаторами сборок; при возврате библиотек
на место ссылки в проекте не порвутся.

SwfDotNet.IO.dll, версия 0.9.0.42093
    Разбор двоичного формата swf: теги, символы, фигуры, текстовые поля.
    UniFlash использует её при импорте swf, чтобы превратить ролик
    в бинарный ассет Unity (см. EditorTools/SwfToBinaryConverterTool.cs).
    Автор: Olivier Carpentier (Adelina foundation), с наработками
    библиотеки SwfOp (Florian Krusch, 2004).
    Лицензия: GNU General Public License (заголовки первоисточника
    противоречиво называют её "GPL ... version 2.1").
    Где взять: sourceforge.net/projects/swfdotnet/

SharpZipLib.dll, версия 0.81.0.1407
    Распаковка сжатых swf (Deflate) и работа с архивами.
    Правообладатель по метаданным: Mike Krueger, 2001-2004, #ZipLibrary.
    Лицензия: GNU GPL v2 с исключением для связывания; с версии 1.0
    проект перешёл на MIT.
    Где взять: github.com/icsharpcode/SharpZipLib

Почему удалены
    Обе — копилефтные (GPL), а репозиторий выложен на условиях
    проприетарной оферты NIVAL INTERNATIONAL LTD. (LICENSE.md).
    Совмещение требует отдельной правовой оценки, поэтому сборки
    из публикации исключены.

Как вернуть
    Скачать обе библиотеки по ссылкам выше и положить в эту папку рядом
    с существующими .meta. Без них не соберётся редакторская часть
    UniFlash (импорт swf); рантайм проигрывания уже готовых бинарных
    ассетов от них не зависит.
