Библиотеки, удалённые из этой папки

Здесь лежали две сторонние сборки, необходимые инструментам работы с swf
(SwfValidator.exe, скрипты Swf2Xml.bat и ValidateSwf.bat остаются на месте).

SwfDotNet.IO.dll, версия 0.9.0.42093
    Чтение и запись двоичных swf-файлов на C#: разбор тегов, извлечение
    символов, фигур, текстовых полей и звуков. Использовалась для
    конвертации swf в xml и проверки содержимого роликов интерфейса.
    Автор: Olivier Carpentier (Adelina foundation), с использованием
    наработок библиотеки SwfOp (Florian Krusch, 2004).
    Лицензия: GNU General Public License. Заголовки исходных файлов
    библиотеки называют её "GNU General Public License ... version 2.1",
    хотя номер 2.1 принадлежит LGPL — формулировка первоисточника
    противоречива, и это стоит учитывать при использовании.
    Где взять: sourceforge.net/projects/swfdotnet/

SharpZipLib.dll, версия 0.81.0.1407
    Сжатие и распаковка (Deflate, Zip, GZip, Tar) на C#. Нужна
    SwfDotNet.IO для чтения сжатых swf.
    Правообладатель по метаданным сборки: Mike Krueger, 2001-2004,
    продукт #ZipLibrary (ICSharpCode).
    Лицензия: GNU GPL версии 2 с исключением, разрешающим связывание
    с независимыми модулями. Начиная с версии 1.0 проект перешёл на MIT.
    Где взять: github.com/icsharpcode/SharpZipLib

Почему удалены
    Обе библиотеки распространяются под копилефтной лицензией GPL,
    тогда как настоящий репозиторий выложен на условиях лицензионной
    оферты NIVAL INTERNATIONAL LTD. (см. LICENSE.md), запрещающей
    коммерческое использование. Совмещение этих условий в одном
    дистрибутиве требует отдельной правовой оценки, поэтому сами сборки
    из публикации исключены, а код, который их использует, оставлен.

Как вернуть для работы инструментов
    Загрузить обе библиотеки по ссылкам выше (SharpZipLib — версии 0.8x,
    так как API более новых версий отличается) и положить рядом
    с SwfValidator.exe.
